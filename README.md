# 罗德岛终端 (Rhodes Island Terminal)

面向 **《明日方舟》** 与 **《明日方舟：终末地》** 的跨游戏战略数据终端，支持 **独立安卓 APK** 与 **Web / PC 本地终端** 双形态运行。

---

## 核心功能

### 1. 双主题视觉系统
- **明日方舟 · 舟味战术风格**：深碳黑 `#0A0C0F`、PRTS 青 `#22BBFF`、干员琥珀 `#FF9A2E`、45° 切角战术面板与网格底纹。
- **终末地 · 塔卫二工业风格**：高反差工业水泥浅灰 `#E9ECEF`、厚重碳黑结构块 `#14161A`、警示黄 `#FFE600`、工程点阵与斜纹警示条。

### 2. 明日方舟板块
- **罗德岛总览**：博士等级、官服/B服标识、当前理智恢复水位、干员统计与各模块速览。
- **寻访分析（抽卡统计）**：参照高可读卡片流风格展示总消耗合成玉、欧气称号与成就徽章、限定/标准/中坚三类概览及三轨独立已垫进度（50 抽后每抽 +2% 软保底）；每个寻访卡池单独成卡（含暂无六星的卡池），支持一键切换展示五星、展开单池明细与全库检索，并支持 JSON 导入/导出。
- **卫戍协议战绩**：对接森空岛卫戍协议战绩接口，展示赛季总局数、通关率、最佳难度、奖杯数、按激活次数排序的前三常用盟约与折叠展开、单局盟约层数/完整阵容/首领击杀详情。
- **集成战略战绩**：对照森空岛数据完整拉取全部主题（沉沦者的黑流树海、岁的界园志异、萨卡兹的无终奇语、探索者的银凇止境、水月与深蓝之树、傀影与猩红孤钻），精准还原藏品解锁数、源石锭投资、真实结局中文名称，支持最近/收藏记录切换及可点击的单局战绩详情弹窗（历程回顾、招募干员、专属通宝/零件与收藏品明细）。
- **PRTS.WIKI 应用内直连**：内置独立 WebView 页面（Android 原生 `PrtsWebActivity` / Web 站内弹窗），支持首页直达、词条搜索与热门专题点击，无需跳转外部浏览器。

### 3. 终末地板块
- **寻访工业数据分析**：支持特许寻访（限定 UP）、基础寻访（常驻）、启程寻访（新手）与武库申领（武器）。
- **双轨保底追踪**：
  - **80 抽 6★ 小保底**（跨同类型池继承，武器池 40 抽小保底）。
  - **120 抽当期 UP 大保底**（按单期卡池独立计算、不跨池继承，清晰标注剩余抽数）。
- 支持鹰角账号同步与粘贴 `ef-webview.hypergryph.com` 抽卡链接一键抓取。

### 4. 双游戏独立账号与演示模式
- 支持 **明日方舟** 与 **终末地** 账号完全独立登录、切换 UID、同步与退出，互不覆盖。
- 支持手机号短信验证码登录、密码登录、森空岛 `cred` / `sign_token` 导入、方舟 `u8_token` / 终末地链接导入（兼容官服与 B 服）。
- 内置一键切换的 **演示数据模式（DEMO）**，无需登录即可完整体验全部界面与图表。

## 安卓手机安装（独立 APK）

前往本仓库的 [**Releases**](../../releases) 页面下载最新 `RhodesIslandTerminal-v1.3.0.apk`，在手机端直接安装即可。安卓端内置 `CapacitorHttp` 原生通道，手机直连鹰角/森空岛/终末地接口，无需在电脑端启动后台服务。

## 本地开发与构建

### 1. 安装依赖
```bash
npm install
```

### 2. Web / PC 本地运行
- 开发模式（Vite 前端 `5173` + Express 本地代理 `3001`）：
  ```bash
  npm run dev
  ```
- 生产构建与启动（单端口 `3000`）：
  ```bash
  npm run build
  npm start
  ```

### 3. 类型检查与单元测试
```bash
npm run typecheck
npm test
```

### 4. 构建 Android APK
确保已安装 JDK 21、Android SDK（Platform 35）与 Gradle，在 `android/local.properties` 配置 `sdk.dir` 后执行：
```bash
npm run cap:sync
gradle -p android assembleDebug
```
